# استوديو نور التعليمي — Noor Learning Studio

مشروع الأستاذ أحمد الضامري لدروس تقنية المعلومات: مكتبة تفاعلية، تحاضير من حصتين، محرر محتوى محلي، وإضافة Firefox لنور. موقع ثابت يمكن نشره على GitHub Pages أو استخدامه دون اتصال.

## المتاح في الإصدار 1.5.0

- الخامس: ثلاث وحدات، 11 درسًا ومشروعان، 30 حصة رسمية و4 حصص تعزيز في 17 لقاءً، و65 سؤالًا ومختبرات محلية وملفات التطبيق الأصلية. اكتمل المحتوى، وتبقى مطابقة أسماء وأهداف نور قبل اعتماد التحاضير.

- اكتمل محتوى الصف التاسع للفصل الأول: 11 درسًا في قواعد البيانات والشبكات، مع 34 حصة رسمية و6 حصص تعزيز ومختبرات تفاعلية. بقيت أهدافه مسودة للمراجعة؛ لم تُختلق معرفات نور ولم تُفعّل التعبئة الرسمية قبل رصدها.

- الثامن، الفصل الأول: 3 وحدات و13 درسًا و16 لقاءً، 30 حصة رسمية وحصتان إضافيتان للتعزيز؛ وفق الخطة الفصلية لمسقط 2026/2027.
- 65 سؤالًا إضافيًا للثامن بتفسير، عروض شرح متدرجة، ومختبرات النماذج والدوال والبايثون والشروط والتجارة والخصوصية.
- الخطة الفصلية مدمجة بالتواريخ، ومحتوى الثامن مستند إلى كتاب الطالب ص16–154 بشرح وأمثلة أصلية.
- أهداف الثامن وأسماء الشجرة تحتاج مراجعة داخل نور؛ لم تُرصد معرفاتها الرسمية ولم يجر اختبار التعبئة داخل جلسة نور.
- السابع، الفصل الأول: 3 وحدات و12 درسًا و16 لقاءً، كل لقاء حصتان 40 + 40 دقيقة.
- 28 حصة وفق الدليل + 4 حصص تطبيق إضافية معلنة لتنظيم الدروس الفردية في لقاءات متتالية.
- شرح وأمثلة ومهمات وتغذية راجعة، وتحديات اختيار وترتيب، وتقدم وتأملات محلية.
- خط عربي كبير، RTL، تصميم متجاوب، مظهر فاتح وداكن، مؤقت وأصوات تعزيز اختيارية واحترام تقليل الحركة.
- عروض للطالب والمعلم وولي الأمر، وطباعة القسم المعروض من اللقاء.
- تطوير نصوص الدرس محليًا، إنشاء مسودة منهج، استيراد وتصدير حزمة موحدة.
- إضافة واحدة لجميع وحدات السابع والثامن والتاسع، مع بنية تسمح بتوسيع المناهج وتعبئة ستة حقول نور من البيانات نفسها.
- محتوى الصفين الخامس والسادس مكتمل للفصل الأول وفق مصادرهما؛ أهداف نور تحتاج المراجعة.

## التشغيل

افتح `index.html` مباشرة بعد فك ضغط المشروع؛ البيانات والأنماط محلية ولا تعتمد على شبكة أو خطوط خارجية. يمكن أيضًا:

```bash
npm test
npm run build
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`. Node 18 أو أحدث وPython 3 للبناء والتغليف، ولا توجد حزم npm تحتاج إلى تثبيت.

## نشر مستودع مستقل على GitHub

اسم مقترح: `noor-learning-studio`. المشروع لا يغير مستودعات الصفوف السابقة.

1. أنشئ المستودع الفارغ في حسابك؛ ارفع محتويات هذا المجلد إلى جذر المستودع، وليس المجلد الأب كاملًا.
2. استخدم الفرع `main`.
3. من Settings → Pages اختر Source: GitHub Actions.
4. شغل workflow أو ادفع تعديلًا إلى main. يفحص المحتوى ويبنيه ثم ينشر الموقع.
5. في حساب sc1561 يكون الرابط المتوقع بعد نجاح النشر `https://sc1561.github.io/noor-learning-studio/`. هذا عنوان متوقع وليس تأكيد نشر.

عند العمل بأوامر Git على جهازك، بعد إنشاء المستودع:

```bash
git init -b main
git add .
git commit -m "Create integrated Noor learning studio"
git remote add origin https://github.com/sc1561/noor-learning-studio.git
git push -u origin main
```

لا تضع رموز GitHub أو بيانات دخول نور في المشروع.

## دورة تطوير واحدة للموقع والإضافة

`content/catalog.json` هو مصدر المحتوى المعتمد. `assets/core.js` يتحقق من المخطط ويولد خطط التحضير وHTML الآمن. أمر البناء يولد بيانات الموقع ومكتبة الإضافة وZIP الإضافة من المصدر نفسه.

من استوديو المتصفح يمكنك تطوير محتوى ثم تصدير `noor-studio-content-pack.json`. احتفظ بنسخة المصدر، وانقل قيمة `catalog` من الحزمة إلى `content/catalog.json`، ثم نفذ الاختبارات والبناء. التعديلات في المتصفح محلية ولا تكتب إلى GitHub تلقائيًا. يمكن استيراد الحزمة مباشرة إلى إضافة Firefox للاستخدام المحلي قبل دمجها في المستودع.

| الوحدة | حصص الدليل | اللقاءات | التطبيق الإضافي |

الأنشطة والتعزيزات توسع تعليمي داخل وقت النشاط، وليست اقتباسًا حرفيًا من الكتاب. مراجع الصفحات موضحة لكل درس. لم ترفع نسخ الكتب أو صورها المحمية في المشروع العام.

أهداف الوحدتين الأولى والثانية وقيمها مأخوذة من خيارات نور المرصودة سابقًا. أهداف الثالثة من دليل المعلم وتحتاج مراجعة في نور. عند اختلاف الصياغة أو أهداف المشروع تترك الإضافة خيارات الأهداف دون تغيير وتطلب اختيارها يدويًا؛ لا تختلق معرفات أو أهدافًا رسمية.

## إضافة Firefox

`downloads/noor-studio-extension-v1.5.3.zip` جاهز. انظر [دليل نور](docs/NOOR.md). معرف الإضافة ثابت لاستبدال إضافات الوحدات السابقة، لكن التخزين الجديد منفصل. لا ترفع واجبات أو مرفقات، ولا تحفظ أو تنشر تلقائيًا.

## بيانات المستخدم وحدود الإصدار

- المفضلة والتقدم والتأملات وتطوير المحتوى محفوظة في المتصفح، دون حساب أو خادم أو مزامنة. التصفح الخاص قد يفقدها.
- اختيار الدور ينظم العرض ولا يفرض صلاحيات أمنية.
- تأكيد الدراسة والتدريب ليس درجة رسمية أو إثبات حضور.
- لا يتصل الموقع العام بحساب نور؛ الإضافة وحدها تعمل في جلسة Firefox المفتوحة على نور.
- مراجعة المصدر وتوزيع حصص المنهج الجديد واعتماد الأهداف مسؤولية المعلم قبل تحويل المسودة إلى جاهزة.
- الاختبارات محلية وتشمل المخطط والأزمنة وتوليد الحقول وحدود رسائل الإضافة. يلزم تجربة الإضافة المتكاملة داخل نور. لم يتحقق النشر الفعلي أو الاختبار البصري داخل متصفح في هذا الإصدار.
