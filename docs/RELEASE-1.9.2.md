# 1.9.2 · رحلة تعلمي

عرض المناهج الحالية مع اختيار الصف والمادة والفصل، وتقدم كل منهج ووحدة، وقائمة الدروس وروابط البدء والمراجعة، وزر متابعة أول درس لم يؤكد المستخدم دراسته. شارة للدروس ذات التحضير المطور، وعدد اللقاءات والأسئلة التي راجعها المستخدم. المفضلة والتأملات تتبع المنهج المختار. لا يعد التأكيد إتقانًا أو درجة رسمية.

الواجهة تستمد بياناتها من المكتبة الحالية وتحتفظ بسجل المستخدم المحلي. كان القسم السابق يقدم ملخصًا عامًا دون قائمة دروس وروابط متابعة. نجحت اختبارات عرض الصفين العاشر والثاني عشر وتصفية السابع، وكامل اختبارات المشروع. لم تجر معاينة بصرية في متصفح في هذه الجلسة.

تحديث للموقع فقط؛ إضافة Firefox تبقى 1.9.1 لأن تعبئة التحاضير لم تتغير. وصف القسم الجديد ينتظر المستخدم.
