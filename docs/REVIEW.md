# مراجعة قبل إصدار منهج

- المصدر والصفحات وتوزيع الحصص موثقة.
- لكل حصة هدف ومهمة وشاهد تعلم، والمجموع 40 دقيقة.
- كل لقاء حصتان، والحصص الإضافية معلنة منفصلة عن توزيع الدليل.
- noorTitle مطابق للوحدة والدرس في الشجرة.
- معرفات الأهداف رصدت فعلًا؛ إن لم ترصد يستخدم teacher-guide وreview.
- المسودات واضحة ولا تقدم كمحتوى جاهز.
- الأسئلة لها خيارات سليمة وتفسير مفيد.
- تحقق القراءة على الهاتف والمظهرين وقابلية الطباعة قبل اعتماد تصميم جديد.
- جرب تحضيرًا واحدًا داخل نور، وراجع الأسبوع والتواريخ والشعب والحصتين قبل الحفظ.
- شغل npm test وnpm run build بعد تعديل المصدر.
