# 1.9.1 · تعميم تحاضير السابع

عممنا تصميم الأقسام الستة على 12 درسًا في الوحدات الثلاث للسابع، و16 لقاء من حصتين. بقيت 28 حصة رسمية و4 حصص تعزيز كما في المحتوى السابق؛ لم يتغير توزيع الحصص أو المخرجات أو معرفات نور. بقيت مناهج الصفوف الأخرى على تصميمها السابق.

المفاهيم والشرح والأمثلة في بطاقات مستقلة، وأدوار المعلم والمتعلم والنواتج داخل الإجراءات، وتقويم ودعم وإثراء وبديل ورقي مناسب للمهارة. يظهر زمن التهيئة والخروج من خطوات الحصة الفعلية دون افتراض زمن موحد. حصص التعزيز مميزة. الملاحظات الأسبوعية لكل لقاء مستمدة من موضوعه ومخرجاته ورسالة ولي الأمر، دون إدخال محتوى درس الذكاء الاصطناعي في بقية الدروس.

أثرينا مهام الأجيال وتشخيص التقنيات وتحكيم التصميم وتمثيل هيكليات الشبكات واختيار الجهاز وتشخيص بلاغ الصوت، استنادًا إلى الحزمة التدريبية ودليل حل الأنشطة المرفقين. التكييف ضمن الزمن القائم؛ لم ننقل أزمنة ورشة التدريب مباشرة أو ننشر كامل دليل الإجابات.

هذا التعميم لتنسيق التحاضير ومهامها الصفية؛ لم نضف محاكاة برمجية جديدة لكل نشاط. مختبر التوجيه والتحقق المحلي في درس الذكاء الاصطناعي التوليدي قائم.

تحدث الدروس الأصلية غير المعدلة تلقائيًا، وتحتفظ المكتبة بالتعديل المحلي إذا اختلف عن النسخة الأصلية. لرؤية النسخة المرفقة بدل تعديل قديم: صدّر مكتبتك ثم استعد المحتوى المرفق. التنسيق وعناصر الكشف يحتاجان تجربة حفظ فعلية داخل نور؛ لم تجر هذه التجربة أو معاينة واجهة في متصفح في هذه الجلسة.

نجح npm run build وكامل npm test، بما يشمل جميع لقاءات السابع والأزمنة ومؤشرات الدعم والأقسام المستقلة والمناهج السابقة.
