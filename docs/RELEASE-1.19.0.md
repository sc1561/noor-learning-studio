# الإصدار 1.19.0 — مراجعة البنك ومراجعة الوحدة

يبقى البنك عند 624 سؤالًا في 76 درسًا ومشروعًا. تشمل المراجعة التحريرية تحسين بدائل 83 سؤالًا، وتحديد عناصر الإجابة في 125 حالة ذات معايير عامة، وتعديل سؤالين متقاربين، وتصحيح 8 تصنيفات معرفية وإضافة تفسير لستة أسئلة. وُزعت الإجابة الصحيحة بالتساوي بحسب عدد الخيارات، دون تغيير معنى مفتاح الإجابة.

اختيار «مراجعة الوحدة · جميع دروسها» من قائمة الدرس يعرض أسئلة الوحدة بترتيب دروسها، مع اسم درس السؤال الحالي. تغيير الصف أو الوحدة أو الدرس أو النوع يخفي الإجابة والاختيار السابق. يبقى النسخ نصيًا والعرض سؤالًا واحدًا؛ لا توجد طباعة أو تصدير أوراق.

التحقق: اختبارات المشروع، سلامة الخيارات والدرجات، أمثلة حسابية، فصل الصفوف والوحدات والأنواع، ترتيب الدروس، وتجربة معالجات تغيير الاختيارات وإخفاء الإجابة في محاكاة DOM. لا تتضمن هذه الجولة معاينة بصرية فعلية في متصفح، ولا اعتمادًا رسميًا للأسئلة أو مراجعة مستقلة من مختص؛ يبقى تقويم المعلم ضروريًا قبل الامتحان.
