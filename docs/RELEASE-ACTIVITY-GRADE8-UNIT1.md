# نشر نشاط مراجعة الوحدة الأولى للصف الثامن

أضيفت صفحة HTML مستقلة بعنوان «مراجعة لما درسته في الوحدة الأولى» لتوفير رابط مباشر للنشاط.

- المحتوى: عشرة أسئلة اختيار من متعدد عن النماذج الإلكترونية، وتحليل البيانات، والنماذج الحاسوبية، وفق كتاب الطالب للصف الثامن.
- الصفحة تعمل دون أصول أو خطوط خارجية، وتُعرض مباشرة ضمن GitHub Pages.
- أقسام مكتبة الدروس، ورحلة التعلم، واستوديو التطوير، وتحاضير نور، وبنك الأسئلة، ودليل المشروع لم تتغير؛ النشاط ملف مستقل ولا يعدل سلوك هذه الأقسام.
- التحقق: فحص بنية JavaScript وعدد الأسئلة والموضوعات المطلوبة. سير النشر الآلي يجري عبر GitHub Pages عند تحديث الفرع main.
