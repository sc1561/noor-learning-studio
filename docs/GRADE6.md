# الصف السادس · الفصل الأول 2026/2027

المصادر: كتاب الطالب للصف السادس، دليل المعلم للفصل الأول، والخطة الفصلية لمحافظة مسقط المرفقة. الشرح والأنشطة التعليمية توسعة مبنية على تلك المصادر، والمحاكاة أمثلة تدريبية محلية لا تشغل Excel أو Tinkercad أو Teams فعليًا.

لكل درس خمسة أسئلة بتفسير، ومختبر محلي، وتوزيع أهداف ومراحل من 40 دقيقة لكل حصة. حفظنا فترات الوحدة الثانية المتداخلة كما وردت بالخطة. الحصة الرابعة لكل درس من ثلاثة حصص موسومة تعزيزًا ولا تضاف إلى التخصيص الرسمي.

المرفقات الأصلية محفوظة في downloads/grade6 مع فصل نسخ الطالب والمعلم؛ لا تعدّل ملفات Excel وWord الأصلية. أهداف الدليل دون معرفات نور، وربط كل لقاء draft إلى أن يراجع المعلم شجرة الأهداف الرسمية. اكتمال محتوى التعلم لا يعني اعتماد التعبئة الآلية في نور.

الإصدار 1.5.0 يضم المحتوى في الموقع وحزمة الاستيراد وإضافة Firefox. النسخة المحلية القديمة ذات مسار السادس الفارغ تستقبل المسار المضاف تلقائيًا، مع حفظ تعديلات المستخدم على المناهج الأخرى.

التحقق: npm test وnpm run build. اختبار السادس يفحص الحصص والأسئلة والمرفقات والتجويف والصيغ والتصفية والسلامة. تعذر فحص الصور في Chromium لعدم تثبيت متصفح الاختبار؛ اختبارات مسارات الواجهة نجحت.
